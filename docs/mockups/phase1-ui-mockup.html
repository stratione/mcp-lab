Reading a scan like an engineer

A scanner doesn’t say your app is “insecure.” It says: this package, at this version, inside this image, has this known defect — and here is the version that fixes it. That’s an actionable sentence, and it’s the whole basis of the patch → rescan loop you’ll run in module 05.
